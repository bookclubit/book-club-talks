Декларативный подход естественен для баз данных: СУБД сама выбирает и оптимизирует план запроса.

Это одна из причинпопулярности SQL

Текст В прошлом докладе мы видели, как реляционная модель победила IMS и CODASYL. Одно из её главных новшеств — новый способ спрашивать данные. SQL — декларативный язык запросов, а IMS и CODASYL выполняли запросы императивным кодом. Декларативный подход хорошо подходит для баз данных: СУБД сама выбирает и оптимизирует способ получения результата. Это одна из причин популярности SQL. Что это значит и почему это важно — весь этот доклад.

Переход Начнём с императивного кода, который пишет каждый из нас.

02Императивно

Императивный код: как — шаг за шагом

Компьютер выполняет операции в заданном порядке: строка за строкой, условие, переменная, ещё круг цикла

function getSharks() {  var sharks = [];  for (var i = 0; i < animals.length; i++) {    if (animals[i].family === "Sharks") {      sharks.push(animals[i]);    }  }  return sharks;}
animals · перебираем по одному
Great WhiteSharks Blue WhaleWhales Tiger SharkSharks DolphinDolphins HammerheadSharks HumpbackWhales
sharks · собираем руками
Great WhiteTiger SharkHammerhead

Текст Большинство распространённых языков программирования — императивные. Пример из книги: есть список животных, нужно получить из него только акул. Пишем функцию: заводим пустой массив, идём циклом по всем животным, проверяем семейство, складываем подходящих.

Текст Императивный язык говорит компьютеру выполнить определённые операции в заданном порядке. Можно представить это как движение по коду строка за строкой: вычисляем условие, обновляем переменную, решаем, пройти ли цикл ещё раз.

Как показывать Справа анимация: курсор идёт по животным по одному, акулы падают в результат. Список животных — моя иллюстрация, функция — из книги.

Переход А теперь то же самое на языке математики.

03Декларативно

Декларативный запрос: что — шаблон результата

реляционная алгебра
sharks = σfamily = Sharks (animals)
SQL 
SELECT * FROM animals WHERE family = 'Sharks';

Как показывать Наведите на σ, условие или animals — подсветится соответствующая часть SQL.

Текст В реляционной алгебре то же самое пишется одной строкой: sharks равно сигма с условием family равно Sharks от animals. Сигма — оператор выбора: возвращает только тех животных, которые соответствуют условию. SQL весьма близко следует структуре реляционной алгебры: SELECT звёздочка FROM animals WHERE family равно Sharks.

Текст В декларативных языках описывают шаблон нужных данных: каким условиям должны соответствовать результаты и как их преобразовать — отсортировать, сгруппировать, агрегировать. Но не то, как этого добиться. Какие индексы и методы соединения использовать, в каком порядке выполнять части запроса — решает оптимизатор.

Как показывать В русском издании в сноске формула переведена: «акулы = σ семейство = Акулы (животные)».

Переход Хорошо, запрос короче. Но короткость — не главное.

04Почему декларативно · 1

Запрос не знает реализации — базе можно ускоряться

База хочет освободить место на диске и перетасовать записи. Не сломает ли она существующие запросы?

Императивный код · порядок зашит
Great WhiteTiger SharkHammerhead
// а вдруг код рассчитывает на порядок?
const first = getSharks()[0];

База не может быть уверена, важен ли порядок для кода, — значит, трогать данные опасно

SQL · порядок не обещан
Great WhiteTiger SharkHammerhead
SELECT * FROM animals WHERE family = 'Sharks';
-- нужен порядок? скажите явно: ORDER BY

Результат — множество, порядок не гарантирован. Базе можно перекладывать записи как угодно

Текст Декларативные языки привлекательны, потому что короче и удобнее императивных API. Но важнее другое: они скрывают подробности реализации ядра базы, и у СУБД появляется возможность повышать производительность, не меняя запросов.

Текст Пример из книги. Императивный код выше возвращает животных в определённом порядке. Допустим, базе понадобилось незаметно освободить неиспользуемое место на диске, и для этого надо перетасовать записи — порядок изменится. Сможет ли база сделать это безопасно? Запрос на SQL не гарантирует никакого порядка, поэтому ему всё равно. А если запрос написан императивным кодом, база не может знать, рассчитывает ли код на порядок.

Как показывать Строки в обеих колонках меняются местами — слева это риск, справа норма. Строка с getSharks()[0] — моя иллюстрация.

Текст У декларативных языков шансы выше: они задают только шаблон результата, а не алгоритм его получения. База при желании может выполнить запрос параллельно — поделить данные между ядрами или машинами.

07Запросы с помощью MapReduce

MapReduce — нечто среднее

Модель обработки больших объёмов данных блоками на множестве машин, которую продвигала Google (2004). В ограниченном виде её поддерживают MongoDB и CouchDB — для запросов на чтение по многим документам

документы mapна каждый документ пары ключ — значение группировка по ключу reduceна каждый ключ результат

Текст MapReduce — модель программирования для обработки больших объёмов данных блоками на множестве машин, её активно продвигала Google. В ограниченном виде MapReduce поддерживают некоторые NoSQL-хранилища, включая MongoDB и CouchDB, — как механизм запросов только на чтение по многим документам. Подробно MapReduce разбирается в главе 10, сейчас — коротко и на примере MongoDB.

Текст MapReduce — ни декларативный язык запросов, ни полностью императивный API. Нечто среднее: логика запроса выражается фрагментами кода, которые фреймворк вызывает многократно. Основа — функции map, она же collect, и reduce, она же fold или inject, из функциональных языков. Нам они знакомы по массивам в JavaScript.

Как показывать Наведите на любой блок схемы или выберите его клавишей Tab: появится пример кода или данных для этого шага.

Задача биолога: сколько акул за месяц

Каждое наблюдение животных в океане — запись в базе. Нужен отчёт по месяцам

SELECT date_trunc('month', observation_timestamp)       AS observation_month,       sum(num_animals) AS total_animalsFROM observationsWHERE family = 'Sharks'GROUP BY observation_month;
1

Фильтр: остаются только наблюдения семейства Sharks

2

Группировка по месяцу: date_trunc округляет метку времени до начала месяца

3

Сумма животных в каждом месяце

Как показывать Наведите на шаг справа — подсветятся строки запроса.

Текст Допустим, вы морской биолог и каждый раз, когда видите в океане животных, записываете наблюдение в базу. Теперь нужен отчёт: сколько акул вы видели за каждый месяц.

Текст В PostgreSQL это выглядит так. Запрос сначала фильтрует наблюдения, оставляя только семейство Sharks, затем группирует по календарному месяцу и суммирует количество животных. Функция date_trunc с параметром month округляет метку времени до начала месяца — отбрасывает дробную часть месяца.

Переход А теперь то же самое в MongoDB через MapReduce.

09Запросы с помощью MapReduce

То же в MongoDB: две функции и фильтр

db.observations.mapReduce(  function map() {    var year  = this.observationTimestamp.getFullYear();    var month = this.observationTimestamp.getMonth() + 1;    emit(year + "-" + month, this.numAnimals);  },  function reduce(key, values) {    return Array.sum(values);  },  {    query: { family: "Sharks" },    out: "monthlySharkReport"  });
1

query — фильтр по акулам задан декларативно: расширение MongoDB

2

map вызывается по разу на каждый подходящий документ, this — сам документ

3

emit порождает ключ «год-месяц», например "2013-12", и значение — число животных

4

Пары группируются по ключу, и для каждого ключа один раз вызывается reduce — сумма

5

out — итог пишется в коллекцию monthlySharkReport

Как показывать Наведите на пункт справа — подсветится его часть кода. Удобно идти по пунктам сверху вниз.

Текст То же самое через MapReduce в MongoDB. Фильтр только по акулам задаётся декларативно — это расширение MongoDB к модели MapReduce. Функция map на JavaScript вызывается один раз для каждого документа, подходящего под query, и this в ней — сам документ. Она порождает ключ — строку из года и месяца, например «2013-12» или «2014-1», — и значение — количество животных в наблюдении.

Текст Пары «ключ — значение», порождённые map, группируются по ключу, и для всех пар с одинаковым ключом, то есть с одним месяцем, один раз вызывается reduce. Она суммирует количество животных за месяц. Итог записывается в коллекцию monthlySharkReport.

10Запросы с помощью MapReduce

map и reduce должны быть чистыми

Можно
function map() {
  // разобрать строку, посчитать, вызвать библиотеку
  const [genus] = this.species.split(' ');
  emit(genus, this.numAnimals);
}
  • только входные данные
  • разбор строк, вычисления, библиотечные функции
Нельзя
function map() {
  db.species.findOne({ … });  // запрос к базе
  counter++;                   // побочный эффект
  emit(this.family, this.numAnimals);
}
  • дополнительные запросы к БД
  • побочные эффекты
Зачем
Тогда база может выполнять функции где угодно, в любом порядке и перезапускать их при сбое

Текст Действия, разрешённые map и reduce, ограничены. Эти функции должны быть чистыми: использовать только переданные им входные данные, не выполнять дополнительных запросов к базе и не иметь побочных эффектов.

Текст Эти ограничения позволяют базе выполнять функции где угодно, в любом порядке и перезапускать их в случае сбоя. При этом возможностей у них немало: они могут разбирать строки, вызывать библиотечные функции, выполнять вычисления.

Как показывать Оба примера кода — мои иллюстрации; React-разработчикам это знакомо по требованию чистоты от компонентов и редьюсеров.

Почему отказались от MapReduce

Неудобно

Две тщательно согласованные функции —
обычно сложнее, чем один запрос.

Сложнее оптимизировать

Декларативный запрос даёт оптимизатору
больше возможностей ускорить выполнение.

Текст Главная проблема MapReduce для запросов — нужно написать и согласовать две функции. Один декларативный запрос обычно проще, а оптимизатор получает больше свободы при выборе способа выполнения.

MongoDB 2.2: конвейер агрегирования

Документы проходят стадии по очереди: выход одной становится входом следующей

aggregation pipeline
db.observations.aggregate([  { $match: { family: "Sharks" } },  { $group: {    _id: {      year:  { $year:  "$observationTimestamp" },      month: { $month: "$observationTimestamp" }    },    totalAnimals: { $sum: "$numAnimals" }  } }]);

Как показывать Наведите на стадию трубы — подсветится соответствующая часть кода.

Текст Именно из-за этих неудобств в версии 2.2 в MongoDB добавили поддержку декларативного языка запросов — конвейера агрегирования, aggregation pipeline. Тот же подсчёт акул: стадия $match фильтрует, $group группирует по году и месяцу, $sum суммирует.

Текст По выразительности конвейер напоминает подмножество SQL, но использует синтаксис на основе JSON, а не фразы в стиле английского языка. Это, вероятно, дело вкуса.

Как показывать Уже после книги, начиная с MongoDB 5.0, mapReduce объявлен устаревшим: документация советует конвейер агрегирования.
